# Dongwon Son

Source for [dongwon-son.github.io](https://dongwon-son.github.io/), Dongwon Son's academic homepage.

The site is built with Jekyll and the al-folio academic theme. It highlights research in robot learning for manipulation, computationally efficient simulation, planning, and sim-to-real transfer.

## Local Development

```bash
bundle install
bundle exec jekyll serve
```

Then open `http://127.0.0.1:4000/`.
